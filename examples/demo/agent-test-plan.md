# 咨询师筛选网页 Agent 测试方案

## 依据与范围

- PRD：`../example-lite-filter.md`，v1.0；执行用例：`demo-test-cases.yaml`；人工评审表：`../example-test-cases.md`。
- 范围：F-01 咨询师列表筛选和关联回归，TC-001 至 TC-007；不覆盖真实预约与支付。此方案使用演示页面，结果不能代表真实系统。

## 执行条件

- 测试环境：本地演示网页；在 YAML 的 `ENTRY` 填写本机 `lite-filter-demo.html` 地址。
- 测试数据：D1 使用演示页面默认数据；D2 在页面的「演示数据」区域选择「今天无可约」。
- 工具：能操作网页并保存截图的 Agent 浏览器。开始前确认环境、入口、范围、数据和工具，等待用户确认。

## 执行和报告

读取 PRD 和 YAML，按 TC-001 至 TC-007 的 setup、steps、expect、cleanup 操作，基于页面可见文字定位；不按实际界面改写预期。每条结束截图，失败时另截失败步骤。无法定位、缺数据或页面不可用时如实记录，不猜测通过；生产环境限制按测试执行技能处理。

按测试执行技能的结果格式先给出上线结论，再交付逐条结果、实际现象、截图、通过与失败等统计、缺陷草稿及未覆盖原因。将本方案、PRD 和 YAML 一起交给测试 Agent，确认后执行。
