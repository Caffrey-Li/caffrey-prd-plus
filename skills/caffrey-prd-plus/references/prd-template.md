# PRD 核心模版

本文件是 PRD 的固定骨架。以 `> 写法：` 开头的引用块是写给你（AI）的说明，**输出 PRD 时必须删除**。表格表头保持不变，行数按实际内容增减。

章节属性：**必填** = 任何规模都保留；**条件** = 按 `section-matrix.md` 和类型判断；**可选** = 用户要求或内容充足时才写。

> 写法：必填。信息卡让读者 10 秒内知道这是什么、谁负责、到哪一步了。未知字段写 TBD，不要删行。

**一段话摘要**

> 写法：3-5 句，依次回答：解决谁的什么问题；做什么；预期达到什么结果；最大的风险或依赖是什么。管理层可能只读这一段。

**本版变更摘要**

> 写法：草稿阶段写“首版草稿”。定稿后每次更新写本版改了哪些章节、哪些功能编号，一到三行；完整记录在附录。

**目录**

> 写法：列出本 PRD 实际出现的一级章节。飞书可自动生成目录，这里列章节名即可。

## 一、背景与问题

> 写法：必填。只写“为什么要做”，不写方案。运营配合放第十三章，后续规划放第五章。

- **要解决的问题**：用一两句话描述现状和问题。
- **需求来源**：用户反馈 / 数据发现 / 业务方提出 / 客户合同 / 合规要求 / 战略规划 / 其他。
- **数据与证据**：支撑问题存在和严重程度的数据、案例、反馈；没有数据写 TBD 并说明需要什么数据。
- **为什么现在做**：时间窗口、竞争、成本、合规截止等。
- **为什么由我们做**（可选）：已有能力、资源、渠道优势。
