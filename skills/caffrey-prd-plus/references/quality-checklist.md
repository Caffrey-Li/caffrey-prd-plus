# 自检清单

生成或更新 PRD 后逐项检查。能自行修正的直接改正文；修不了的（缺信息）转成问题清单。最后输出 3-6 行「自检结果」。

## 完整性
- [ ] 文档信息卡每一行都有值或 TBD。
- [ ] 按 `section-matrix.md`，所选文档版本应出现的章节都已出现，且每章是“已填写 / TBD / 不适用：原因”之一。
- [ ] 每个选中类型的模块都写进了第九章，检查项无遗漏。
- [ ] 选中行业包的检查项已写进对应章节。
- [ ] 第十四章至少有一条风险或明确写了“已评估，暂无高风险”。
- [ ] 完整版：8.3 每个模块都有用户路径图，图中页面都在 8.4 有说明或标了“无页面说明”，分支与 8.2、8.4 一致。
- [ ] 8.4 中每个有界面的页面、弹窗都有线框图；有输入或展示字段的页面都有「字段与组件」表和「入口」。

## 一致性
- [ ] 8.1 每个功能在 8.4 或 8.7 有规则，在十二有验收。
- [ ] 8.1 每个功能编号在 8.4 或其他子章节有说明，在第十二章有验收标准。
- [ ] 第三章每个指标在 11.1 有口径（第十一章不出现时除外）。
- [ ] 第六章出现的系统在第八章或第十四章有交代。
- [ ] 第八章页面说明引用的 G-、I- 编号在第七章存在。
- [ ] 线框图中的编号 ①②③ 都在「操作与规则」中有对应说明；图中的按钮、字段和规则里的说法一致。
- [ ] 线框图中的每个输入、选择类组件都在字段表里，且必填、长度 / 格式、默认值都有值、TBD 或“—”。
- [ ] 字段表引用的 D-、E-、R-、Q- 编号都存在；状态只在 8.5 出现。
- [ ] 全文术语一致，与附录名词解释一致。

## 真实性
- [ ] 没有用户未提供的具体数字、人名、部门名、系统名、日期。
- [ ] 推断内容都标了【待确认】。
- [ ] 字段长度、取值范围、枚举值、提示文案不是编的：用户没给的写了 TBD，或给了建议值并标【待确认】。

## 可读性
- [ ] 每句话都不能再删字；没有“说明”“注”“补充”“也就是说”这类补充语和空话。
- [ ] 同一内容只出现在一处（对照 prd-template.md「写作要求」表），其他地方是编号引用。
- [ ] 没有内容的行、列、小节已删除，没有“无”“暂无”“同上”。
- [ ] 每章第一句话是结论。
- [ ] 没有 Mermaid 等需要渲染的图；流程用步骤表，状态用状态流转表。
- [ ] 线框图放在 `text` 代码块里，只画左边框，横线定长，没有颜色、表情符号和装饰，每张不超过 30 行。
- [ ] 验收标准可验证，没有“体验良好”“快速”这类无法验证的描述。

## 自检结果格式

```
## 自检结果
- 完整度：已填写 18 / 待补充 6 / 不适用 3
- 已自动修正：功能 F-04 缺验收标准，已补充
- 需要你补充：核心指标现状数据（第三章）、研发对接人（6.2）
```
