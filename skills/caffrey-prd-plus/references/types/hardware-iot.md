# 类型：硬件 / IoT

**识别信号**：实体设备、传感器、智能硬件、设备联网

## 写入「九、类型扩展模块」

小节标题：`9.N 硬件 / IoT`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 硬件规格 | 尺寸、重量、材质、供电、续航、接口、传感器 |
| 外观与结构 | ID 设计、防护等级、使用环境（温度、湿度） |
| 固件与软件协同 | 固件功能、与 App / 云端的通信方式与协议、配网流程 |
| 成本 | BOM 目标成本、售价区间 |
| 认证 | 3C / CE / FCC / SRRC 等所需认证 |
| 可靠性测试 | 跌落、老化、高低温、寿命 |
| 量产与供应链 | 供应商、产能、良率、交期 |
| OTA | 固件升级方式、失败回滚 |
| 售后 | 保修、维修、退换货、远程诊断 |

## 对其他章节的要求

- 十、写使用环境与可靠性指标
- 十三、写量产节点与渠道铺货
- 十四、供应链与认证进度是主要风险

## 优先追问

- 目标成本和售价是多少？
- 需要通过哪些认证？
- 设备如何与 App 或云端通信？

## 通常不适用

- 8.3 用户路径、8.4 页面说明可缩减为配套 App 部分
