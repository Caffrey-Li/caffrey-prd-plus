# 类型：内部工具

**识别信号**：公司内部使用的系统、效率工具、运营后台、审批工具

## 写入「九、类型扩展模块」

小节标题：`9.N 内部工具`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 使用部门与人数 | 谁在用、多少人、使用频率 |
| 替代的现有流程 | 现在怎么做、耗时多少 |
| 效率目标 | 节省多少时间或人力 |
| 权限与操作日志 | 角色、数据权限、关键操作留痕 |
| 培训与推广 | 上线培训、使用手册 |

## 对其他章节的要求

- 三、指标以效率为主

- 现在这项工作怎么做？花多少时间？
- 哪些部门和多少人会用？
