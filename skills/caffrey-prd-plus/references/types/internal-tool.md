# 类型：内部工具

**识别信号**：公司内部使用的系统、效率工具、运营后台、审批工具

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 使用部门与人数 | 谁在用、多少人、使用频率 |
| 替代的现有流程 | 现在怎么做、耗时多少 |
| 效率目标 | 节省多少时间或人力 |
| 权限与操作日志 | 角色、数据权限、关键操作留痕 |
| 培训与推广 | 上线培训、使用手册 |

## 对其他章节的要求

- 三、指标以效率为主

## 优先追问

- 现在这项工作怎么做？花多少时间？
- 哪些部门和多少人会用？

## 通常不适用

- 十三、对外公告
