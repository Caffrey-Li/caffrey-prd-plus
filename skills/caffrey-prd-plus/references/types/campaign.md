# 类型：运营活动

**识别信号**：促销、拉新、节日活动、积分任务、抽奖、签到等

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 活动时间 | 预热、正式、结束、奖励发放截止时间 |
| 参与条件 | 人群、门槛、次数限制 |
| 玩法规则 | 完整规则与示例，对外规则文案 |
| 奖励与预算 | 奖品清单、库存、发放方式、预算上限、超预算处理 |
| 风控与防刷 | 黑产识别、限频、设备与账号限制 |
| 传播渠道 | 站内入口、推送、短信、社群、外部投放 |
| 下线处理 | 活动结束后的入口、未领奖励、数据保留 |
| 效果复盘 | 复盘指标与时间 |

## 对其他章节的要求

- 三、写参与率、转化、ROI 等指标
- 十三、写运营与客服准备
- 十四、预算超支与被刷是主要风险

## 优先追问

- 活动预算多少？超预算怎么办？
- 活动结束后未领取的奖励如何处理？
- 需要哪些防刷措施？

## 通常不适用

- 五、版本规划可缩减
