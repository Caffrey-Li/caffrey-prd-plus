# 类型：小游戏

**识别信号**：微信 / 抖音等平台上的小游戏

## 写入「九、类型扩展模块」

小节标题：`9.N 小游戏`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 继承 | 包含 Web 游戏模块的全部检查项，在 9.N 中一并写 |
| 平台限制 | 包体积、分包、平台 API 能力 |
| 广告变现 | 激励视频、插屏、Banner 的位置、频次、奖励 |
| 社交裂变 | 分享、排行榜、好友助力 |
| 平台审核 | 类目资质、版号要求、审核风险 |

## 对其他章节的要求
