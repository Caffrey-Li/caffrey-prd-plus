# 类型：小游戏

**识别信号**：微信 / 抖音等平台上的小游戏

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 继承 | 包含 Web 游戏的全部检查项 |
| 平台限制 | 包体积、分包、平台 API 能力 |
| 广告变现 | 激励视频、插屏、Banner 的位置、频次、奖励 |
| 社交裂变 | 分享、排行榜、好友助力 |
| 平台审核 | 类目资质、版号要求、审核风险 |

## 对其他章节的要求

- 十、合规写版号与平台资质

## 优先追问

- 上线哪个平台？
- 主要变现方式是广告还是内购？

## 通常不适用

- 无
