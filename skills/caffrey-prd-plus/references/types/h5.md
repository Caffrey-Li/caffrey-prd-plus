# 类型：H5 页面

**识别信号**：在微信、App 内嵌、浏览器中打开的移动网页

## 写入「九、类型扩展模块」

小节标题：`9.N H5 页面`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 宿主环境 | 微信内、App 内 WebView、外部浏览器的差异 |
| 分享 | 分享标题、描述、图片；朋友圈与好友的差异 |
| 跳转与唤起 | 打开 App、跳转小程序、返回原页面 |
| 登录 | 宿主内免登录方式或授权方式 |
| 性能 | 首屏时间、图片资源大小 |

## 优先追问

- 主要在哪个环境打开？
- 是否需要唤起 App 或跳转小程序？

## 通常不适用

- 无
