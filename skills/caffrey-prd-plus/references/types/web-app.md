# 类型：Web 应用 / 管理后台

**识别信号**：需求运行在浏览器中的系统、后台、工作台、SaaS 页面

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 浏览器兼容 | 支持的浏览器及版本 |
| 分辨率 | 最小支持宽度、是否需要移动端适配 |
| 登录态 | 多标签页、超时退出、单点登录 |
| 批量操作 | 批量选择、批量编辑、操作数量上限 |
| 导入导出 | 文件格式、模板、字段校验、数据量上限、失败处理 |

## 对其他章节的要求

- 七、7.2 补充表格、筛选器等后台通用组件规范

## 优先追问

- 需要支持哪些浏览器？
- 有没有批量操作和导入导出？数据量上限是多少？

## 通常不适用

- 无
