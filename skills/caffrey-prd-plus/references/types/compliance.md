# 类型：合规 / 安全整改

**识别信号**：因法规、审计、监管通知、安全漏洞而做的整改

## 写入「九、类型扩展模块」

小节标题：`9.N 合规 / 安全整改`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 依据 | 法规条款、审计意见、监管通知原文要点 |
| 整改项清单 | 编号、问题、整改方式、责任人 |
| 截止日期 | 监管要求的完成时间 |
| 证据留存 | 整改证明材料、截图、日志 |

## 对其他章节的要求

- 十、合规必写
- 十四、写逾期风险

## 优先追问

- 整改依据是哪条法规或哪份通知？
- 截止日期是哪天？

## 通常不适用

- 三、中的增长类指标（改为合规完成度）
