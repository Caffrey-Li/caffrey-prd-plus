# 类型：合规 / 安全整改

**识别信号**：因法规、审计、监管通知、安全漏洞而做的整改

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 依据 | 法规条款、审计意见、监管通知原文要点 |
| 整改项清单 | 编号、问题、整改方式、责任人 |
| 截止日期 | 监管要求的完成时间 |
| 证据留存 | 整改证明材料、截图、日志 |

## 对其他章节的要求

- 十、合规必写
- 十四、写逾期风险

## 优先追问

- 整改依据是哪条法规或哪份通知？
- 截止日期是哪天？

## 通常不适用

- 三、中的增长类指标（改为合规完成度）
