# 类型：商业化 / 支付

**识别信号**：定价、会员、订阅、支付、退款、结算、发票

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 定价 | 价格、优惠、价格展示规则 |
| 订单与支付状态 | 状态流转（写入 8.5）、超时处理 |
| 支付渠道 | 微信、支付宝、银行卡、苹果内购等，及费率 |
| 退款 | 退款规则、部分退款、审核流程 |
| 对账与结算 | 对账周期、差异处理、分账 |
| 发票 | 开票类型、开票方式 |
| 资金安全 | 重复扣款防护、金额校验、风控 |

## 对其他章节的要求

- 7.1 G-02 金额精度必写
- 十、安全必写

## 优先追问

- 退款规则是什么？
- 需要支持哪些支付渠道？
- 苹果内购是否涉及？

## 通常不适用

- 无
