# 类型：SaaS 标品

**识别信号**：面向多个客户售卖的标准化 SaaS 产品功能

## 检查项

用户没提到、又影响开发的项在第 2 步确认。确认后能写进对应章节的写进去，其余写在第九章，精简版和核心版写在第十四章。无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 版本与套餐 | 不同套餐的功能差异、是否收费 |
| 租户配置 | 租户级配置项与默认值 |
| 老客户兼容 | 对存量客户的影响、迁移方案、通知方式 |
| 帮助文档 | 需要更新的帮助中心内容 |

## 对其他章节的要求

- 十三、写客户通知与客户成功团队准备

## 优先追问

- 这个功能放在哪些套餐？
- 对存量客户有什么影响？

## 通常不涉及

- 无
