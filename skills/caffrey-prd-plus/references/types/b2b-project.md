# 类型：B 端项目驱动型

**识别信号**：为特定客户或合同交付的定制项目、私有化部署、实施项目

## 写入「九、类型扩展模块」

小节标题：`9.N B 端项目驱动型`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 客户背景 | 客户名称（可脱敏）、行业、规模、关键诉求 |
| 合同范围 | 合同或 SOW 约定的交付内容，范围外事项 |
| 验收标准 | 客户验收的条件与方式 |
| 定制与标品 | 哪些是定制、哪些沉淀为标品、对标品的影响 |
| 部署方式 | SaaS / 私有化 / 混合；多租户隔离 |
| 配置项 | 客户可配置的内容 |
| 审批流 | 客户内部的审批流程与角色 |
| 交付里程碑 | 阶段、交付物、时间 |
| 实施与培训 | 实施人员、培训对象与方式 |
| 客户对接人 | 客户侧负责人与联系方式（可脱敏） |

## 对其他章节的要求

- 二、改为“客户与角色”
- 六、6.5 必写客户侧依赖
- 十二、写客户验收标准

## 优先追问

- 合同里约定的验收标准是什么？
- 哪些功能要沉淀为标品？
- 私有化还是 SaaS 部署？

## 通常不适用

- 无
