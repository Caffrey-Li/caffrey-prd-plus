# 类型：策略类

**识别信号**：推荐、排序、风控、定价、匹配、派单、运营规则等以规则或算法为核心的需求

## 写入「九、类型扩展模块」

小节标题：`9.N 策略类`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 策略逻辑 | 输入、判定或计算过程、输出 |
| 规则与参数表 | 参数名、取值、含义、是否可配置、配置人 |
| 生效范围 | 人群、地区、品类、时间 |
| 实验设计 | 分组方式、流量比例、样本量、观察指标、护栏指标、实验周期 |
| 冲突与优先级 | 与现有策略同时命中时的优先级 |
| 回滚条件 | 哪些指标恶化到什么程度立即回滚 |

## 对其他章节的要求

- 三、必须写护栏指标
- 十一、写实验分组埋点

## 优先追问

- 如何验证策略有效？做 AB 实验吗？
- 和现有哪些策略可能冲突？
- 什么情况下回滚？

## 通常不适用

- 8.3 用户路径、8.4 页面说明（无配置后台时）
