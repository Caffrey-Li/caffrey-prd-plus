# 类型：数据类

**识别信号**：报表、看板、指标体系、数据仓库、数据接入、数据产品

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 指标口径 | 每个指标的定义、公式、维度、统计周期（写入 11.1） |
| 数据源与血缘 | 来源系统与表、加工链路 |
| 更新频率 | 实时 / 小时 / 天，及数据就绪时间 |
| 数据质量 | 校验规则、异常告警、补数方式 |
| 权限 | 谁能看哪些数据、脱敏规则 |
| 报表原型 | 在 8.4 用线框图画出筛选区、图表区和明细表的位置（图表写法见 `wireframe.md`）；维度、筛选、下钻用表格描述 |
| 口径冲突 | 与已有报表口径不一致时的说明与处理 |

## 对其他章节的要求

- 六、6.3 数据影响必须填写

## 优先追问

- 这些指标现在有没有别的报表在算？口径一致吗？
- 数据需要多实时？
- 谁能看到这些数据？

## 通常不适用

- 8.3 用户路径、8.5 状态流转
