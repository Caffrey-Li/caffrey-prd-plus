# 类型：开放平台 / API

**识别信号**：对外提供接口、SDK、开放能力给第三方开发者或客户系统

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 接口清单 | 接口名称、用途、调用方 |
| 鉴权 | 密钥、签名、OAuth、IP 白名单 |
| 限流与配额 | QPS、日调用量、超限处理、计费关系 |
| 版本兼容 | 版本号规则、废弃策略、过渡期 |
| 错误码 | 错误码规范与处理建议 |
| 开发者支持 | 文档、示例、沙箱环境、工单渠道 |

## 对其他章节的要求

- 十、写性能与可用性指标

## 优先追问

- 调用方是谁？预计调用量多大？
- 是否收费？与配额如何对应？

## 通常不适用

- 8.3 用户路径、8.4 页面说明（无开发者后台时）
