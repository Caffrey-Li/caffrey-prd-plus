# 类型：内容 / 配置类

**识别信号**：内容上新、配置调整、文案运营、规则参数调整

## 检查项

能写进对应章节的写进去，写不进去的列在第九章（精简版、核心版列在第十四章）。用户没提到、又影响开发的项加入问题清单；无关的项不写。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 配置项清单 | 配置项、取值、生效范围 |
| 配置人与生效方式 | 谁配置、立即生效还是定时、是否需要发版 |
| 审核流程 | 配置是否需要审核 |
| 内容安全 | 敏感词、版权 |

## 优先追问

- 由谁配置？需要审核吗？
- 配置错误如何快速恢复？

## 通常不适用

- 五、版本规划可缩减
