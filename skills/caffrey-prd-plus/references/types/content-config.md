# 类型：内容 / 配置类

**识别信号**：内容上新、配置调整、文案运营、规则参数调整

## 写入「九、类型扩展模块」

小节标题：`9.N 内容 / 配置类`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 配置项清单 | 配置项、取值、生效范围 |
| 配置人与生效方式 | 谁配置、立即生效还是定时、是否需要发版 |
| 审核流程 | 配置是否需要审核 |
| 内容安全 | 敏感词、版权 |

## 优先追问

- 由谁配置？需要审核吗？
- 配置错误如何快速恢复？

## 通常不适用

- 五、版本规划可缩减
