# 类型：小程序

**识别信号**：微信 / 支付宝 / 抖音 / 百度等平台小程序

## 写入「九、类型扩展模块」

小节标题：`9.N 小程序`。逐项填写下表；用户材料未涉及的项写 TBD 并加入问题清单，确实无关的项写【不适用：原因】。

| 检查项 | 要写清楚的内容 |
| --- | --- |
| 平台 | 上线的平台及各平台差异 |
| 平台规则与审核 | 类目资质、审核风险点、平台禁止的功能 |
| 登录与授权 | 手机号授权、用户信息授权、与主账号体系打通 |
| 入口与分享 | 扫码、搜索、分享卡片、公众号或 App 跳转 |
| 包体积 | 主包与分包规划 |
| 消息触达 | 订阅消息模板与触发时机 |

## 对其他章节的要求

- 十、合规写平台类目资质

## 优先追问

- 上线哪些平台？
- 用户身份如何与现有账号打通？
- 需要哪些订阅消息？

## 通常不适用

- 无
