# 行业包索引

行业包不新增章节：检查项写进指定章节，合规项行末加【合规】，不另做汇总。选择“通用”时不加载行业包。

**通用要求（所有行业都检查）**：涉及个人信息时，写明收集目的、最小必要、用户授权与撤回、存储期限；涉及海外用户时，补充目标地区的数据保护要求（如 GDPR）。

法规类检查项以撰写时最新的法规和监管文件为准，PRD 中写明“需法务确认”，不要替法务下结论。
