# 导入说明：写给负责导入飞书的 agent

这是 caffrey-prd-plus 生成的需求文档全包。请导入飞书知识库，保持页面层级、图和文档内跳转，**不改写内容**。

## 包里有什么

| 文件 | 内容 |
| --- | --- |
| `manifest.yaml` | 页面清单和层级、线框图清单、Mermaid 图清单、文档内编号清单 |
| `pages/` | 每个 Wiki 页面一个 Markdown 文件；`pages/01-xxx/` 下是 01-xxx 的子页面 |
| `images/` | 线框图 PNG、Mermaid 图渲染的 PNG；同名 SVG 是源文件，不用导入 |
| `preview.html` | 浏览器预览版：链接可跳转，悬停显示目标内容，跳转后可返回 |

## 导入步骤

1. **确认位置**：问用户导入到哪个知识空间、哪个父节点下。
2. **建节点**：按 `manifest.yaml` 的 `wiki` 顺序和层级创建文档，标题用 `title`。
3. **导入正文**：优先用飞书官方命令行工具 lark-cli 从 Markdown 导入，它会把 `mermaid` 代码块转成飞书画板。用其他方式导入时，按下表转换：

| Markdown | 飞书文档 |
| --- | --- |
| 第一个 `# 标题` | 已作为节点标题，正文中不重复 |
| `##`、`###`、`####` | 标题 2、3、4 |
| 表格 | 表格，第一行为表头 |
| `mermaid` 代码块 | 画板；不能转画板时，插入 `manifest.yaml` 中对应的 diagram PNG，按页面和序号对应 |
| `text` 代码块 | 代码块，语言选纯文本，保持换行和空格 |
| `![说明](../images/xxx.png)` | 上传该图片，在原位置插入 |

4. **处理文档内链接**：正文中的 `[R-01](#R-01)` 是文档内跳转。编号定义在表格第一列或标题开头，清单见 `manifest.yaml` 的 `anchors`。
   - 编号定义在标题上：链接改成该标题的飞书链接，也就是标题的“复制链接”地址。
   - 编号定义在表格行中：链接改成该表格所在小节标题的飞书链接。
   - 编号在另一个页面：链接改成那个页面中对应标题的链接。
5. **核对**：每个页面的标题数、表格数、图片数与 Markdown 一致；每个文档内链接都能跳到正确位置。
6. **汇报**：告诉用户每个节点的链接，以及导入失败的内容。

## 没有 agent 时手动导入

1. 在飞书云文档中选择“导入” → Markdown，逐个导入 `pages/` 下的文件，按 `manifest.yaml` 的层级移动到知识库。
2. 把 `images/` 中的图片拖到对应位置：线框图按图片说明对应；Mermaid 图按 diagram 文件名中的页面序号和图序号对应。
3. 文档内链接需要逐个改成标题链接；不改也不影响阅读，评审时可以用 `preview.html`。
