# Mac、Windows 应用执行指南

## 一、可用方式

| 方式 | 适合 | 怎么准备 |
| --- | --- | --- |
| computer use | 所有桌面应用；不需要改造被测应用 | 在 Claude 桌面版中开启 computer use，按提示授予屏幕录制和辅助功能等权限；被测应用提前安装好 |
| Playwright（Electron 应用） | 用 Electron 开发的桌面应用，可以转成脚本反复运行 | 问研发应用是否基于 Electron；是的话按 `export-playwright.md` 转脚本，用 Playwright 的 Electron 启动方式 |
| 团队已有的桌面自动化框架 | 已有体系时沿用 | 按团队现有配置 |

env 中需要：`ENTRY`（应用名称或安装路径）、测试账号。

## 二、用 computer use 执行

1. 执行前提醒用户：关闭无关应用和通知，执行期间不要操作鼠标键盘。
2. 每步先截图确认画面，再操作；按窗口标题、菜单名、按钮文字定位。
3. 菜单操作写成“菜单 › 子菜单”逐级点击；用例写了快捷键时可以用快捷键。
4. 只操作被测应用的窗口；需要切换到其他应用时先问用户。
5. 涉及系统设置、文件删除、安装卸载的步骤，先问用户。
6. Mac 与 Windows 界面差异（菜单位置、快捷键 Cmd / Ctrl）按当前系统处理，备注写明在哪个系统上执行。
